## Design / Projeto

- Keep the library native to Python `curses`; do not add Textual or a runtime dependency. / Manter a biblioteca nativa em Python `curses`; não adicionar Textual nem dependência de execução.
- Organize public modules by reusable responsibility: semantic color tokens and themes, drawing primitives, native buttons and modal controls, Markdown formatting, and common row layout. Avoid one abstraction per glyph or Markdown token. / Organizar módulos públicos por responsabilidade reutilizável: tokens de cor semânticos e temas, primitivos de desenho, botões e controles de modal nativos, formatação Markdown e layout comum de linhas. Evitar uma abstração por símbolo ou token Markdown.
- Move the byte-identical `specreview/markdown.py` and `occ/markdown.py` implementation into the shared package. Keep viewer policies such as zoom, navigation, selectable-block behavior, selection, cursor, and comments in each plugin. / Mover a implementação idêntica de `specreview/markdown.py` e `occ/markdown.py` para o pacote compartilhado. Manter em cada plugin as políticas do viewer, como zoom, navegação, comportamento dos blocos selecionáveis, seleção, cursor e comentários.
- Extract only stable common wrapping and row-layout behavior. Preserve plugin-specific options and APIs where the two viewers differ. / Extrair somente o comportamento estável e comum de quebra e layout de linhas. Preservar opções e APIs específicas onde os dois viewers diferem.
- Define one shared semantic token contract and named theme IDs, using `herdr-dark` as the visible default while keeping `terminal` as an explicit option. Each plugin reads the same theme setting from its own configuration; missing or invalid values use the visible default. / Definir um contrato compartilhado de tokens semânticos e IDs de temas, usando `herdr-dark` como padrão visual e mantendo `terminal` como opção explícita. Cada plugin lê a mesma opção de tema em sua própria configuração; valores ausentes ou inválidos usam o padrão visual.
- Pressing `t` cycles themes in the open viewer, redraws it immediately, and persists the selected theme in that plugin's configuration. The `?` help lists the shortcut. The viewer does not read or inherit Herdr's active theme. / Pressionar `t` alterna os temas no viewer aberto, redesenha a interface imediatamente e persiste o tema selecionado na configuração daquele plugin. A ajuda `?` lista o atalho. O viewer não lê nem herda o tema ativo do Herdr.
- Shared buttons and modal controls MUST use `curses`, keep keyboard focus and activation usable without a mouse, and accept semantic actions supplied by the plugin. Mouse activation MAY be supported when the terminal reports mouse input. / Botões e controles de modal compartilhados DEVEM usar `curses`, manter foco e ativação por teclado sem exigir mouse e receber ações semânticas fornecidas pelo plugin. A ativação pelo mouse PODE ser oferecida quando o terminal informar suporte a mouse.
- Keep the canonical source in Spec Review and vendor the same complete shared package into both plugins. Provide a maintainer sync/check command and conformance metadata so divergence between either bundle and the canonical release is detectable. / Manter a fonte canônica no Spec Review e embutir o mesmo pacote compartilhado completo nos dois plugins. Fornecer um comando de sincronização/verificação e metadados de conformidade para detectar divergência entre cada cópia e a versão canônica.

## Decisions / Decisões

This is a composable TUI library, not a component framework. Plugins may import only the modules they need and may add local tokens for plugin-only visuals. Both plugins use the same theme IDs and token meanings. Modal controls render and dispatch actions; each plugin retains its own confirmation policy and action semantics. / Esta é uma biblioteca TUI componível, não um framework de componentes. Os plugins podem importar apenas os módulos necessários e adicionar tokens locais para visuais exclusivos. Os dois plugins usam os mesmos IDs de tema e significados de tokens. Os controles de modal desenham e encaminham ações; cada plugin mantém sua política de confirmação e o significado das ações.
